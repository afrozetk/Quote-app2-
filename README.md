# 🤪 Dad Joke Android App

A lighthearted Android app that displays a dad joke and updates with a new one each time the user taps the joke text.  
Built using Java and Android Studio for  IT 372 

---

## 🎯 Features

- Shows a random dad joke on launch
- Tap the screen to reveal a new joke
- Fun and simple interface
- Built using standard Android UI components

---

## 🛠 Tech Stack

- **Language:** Java
- **IDE:** Android Studio

---

## 💻 How to Run

1. Clone or download the project
2. Open it in **Android Studio**
3. Launch it on an emulator or connected device
4. Tap the joke to get a new laugh every time 😄

---

## 🧠 How It Works

- A list of dad jokes is stored in an array
- `TextView` listens for tap events using `setOnClickListener`
- Each tap updates the displayed joke with a randomly selected one
